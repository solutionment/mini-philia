# Definition of Done

- All required CI gates green
- Challenger verdict recorded in the PR
- Delivery report filled in on the PR (what was built, features completed, issues fixed, how to use, known limitations)
- User guide (`docs/user/guide.md`) updated for any change a user can see
- Named human approval on the PR
- Deployed to staging and smoke checked; the release report reached Studio
- Evidence linked: tests, screenshots, eval results
- Work item updated with the PR link and final state
