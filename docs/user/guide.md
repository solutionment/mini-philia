# Mini Philia user guide

Mini Philia helps a nonprofit turn donor and gift spreadsheets into trusted fundraising numbers. This guide is kept current by the Story analyst agent and is included in every release report in SolutionIQ Studio.

## How to access
- **Address:** each release report in Studio (Build, Releases) shows the current address for Testing (staging) and Live (production).
- **Who can sign in:** sign in arrives with work item 04. Until then the app has no user screens.

## What you can do today
- Check that the service is running: open the address followed by `/health`. It shows `"status": "ok"`, the version and the environment.

## Coming next
The backlog in Studio lists what is planned: uploading donor files, cleaned records, quality checked releases of your numbers, a dashboard, and a plain language summary.

## Getting help
Ask your Solutionment contact, or raise a request in Studio (Build, New work item).
