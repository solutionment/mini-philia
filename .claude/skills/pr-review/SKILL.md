---
name: pr-review
description: Checklist for reviewing a pull request in this repository. Use when asked to review a diff.
---
Order: tenant isolation, lineage and trust, migration safety, tests for every new branch, security and PII logging, accessibility and visual regression for UI, AI eval results for prompt changes, scope creep, claims in the PR description that no test proves. Return PASS, PASS WITH NOTES or BLOCK with numbered objections tied to file and line.
